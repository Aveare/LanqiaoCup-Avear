# LanqiaoCup-Avear

蓝桥杯（电子类 / 单片机）备赛资料的归档仓库：真题与题解、备赛资料、笔记、Proteus 仿真电路、STC15 与 STC89C51 的 Keil 工程。

仓库只收**代码、笔记、小文档**。视频、安装包、压缩包、驱动、编译产物都挡在 `.gitignore` 外面，所以仓库保持在 285 MB 左右而不是 1.6 GB。

## 环境

- **Keil uVision 4 / 5 + C51**：打开各目录下的 `.uvproj` 工程
- **STC-ISP**：给 STC15 / STC89C51 下载程序
- **Proteus 8.6+**：低于 8.6 打不开 `02仿真电路图` 里的 `pdsprj`
- 可选：VSCode 编辑、串口调试助手

## 约定

- 工程文件与源码按 **CRLF** 行尾保存（见 `.gitattributes`），Keil 直接可用
- `.c/.h` 里的中文注释多为 **GBK** 编码，用 VSCode 打开需要切到 GBK，否则注释乱码；改动后请保持原编码
- 每份工程保留 `.uvproj`；个人窗口状态（`.uvopt`、`.uvgui.*`）和编译输出不入库

## 没有入库的内容

| 类型 | 规则 | 说明 |
| --- | --- | --- |
| 视频录屏 | `*.mp4` 等 | 约 1 GB，体积过大 |
| 安装包 / 镜像 | `*.exe` `*.msi` `*.iso` | 与源码无关 |
| 压缩包 | `*.zip` `*.rar` `*.7z` | 二进制打包，无法 review |
| 驱动与工具 | `04DP2026…/Tools/`、`*.sys` `*.dll` `*.inf` | 驱动 / 串口助手，按需自行安装 |
| Keil 编译产物 | `*.obj` `*.m51` `*.lst` `*.hex` `Objects/` `Listings/` … | 可由源码重新生成 |
| Proteus 备份 | `*.pdsbak` | 软件自动生成的备份副本 |

需要这些文件时，从本地原始目录取，或单独用网盘 / Git LFS 管理。

## 使用

```bash
git clone https://github.com/Aveare/LanqiaoCup-Avear.git
```

打开某个工程：在 Keil 中 `Project → Open Project`，选择对应目录里的 `.uvproj`，`Rebuild` 后用 STC-ISP 下载。

## 维护

```bash
git add -A
git commit -m "update: 说明改了什么"
git push
```

`.gitignore` 已覆盖常见的噪音文件，`git add -A` 不会再把视频或编译产物带进来。
