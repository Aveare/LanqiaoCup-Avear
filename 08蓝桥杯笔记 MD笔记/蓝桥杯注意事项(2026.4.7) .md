# 蓝桥杯注意事项

## 准备事项

**<u>⭐必看要点：一定要注意题目要求提交的是整个工程，还是单独的hex文件</u>**

**<u>往届比赛两种情况都有过，一般在题目最上方都有写。</u>**

1. 携带准考证、身份证、考试用笔、万用表和直尺（超声波题目测距使用）；
2. 提前30分钟入场，比赛开始30分钟后不得入场；
3. 考试期间有任何问题可联系监考老师；
4. 填空题提交后可以进行修改。在主界面的2个子卷部分，可以重新点击进入修改。

## 考前

1. 到考场后，立刻开机，**敲框架代码**，**测试开发板**。若有问题，及时调换考位和开发板。考试期间遇到任何问题，请与监考老师联系。
2. 查看单片机资源数据包，打开烧录软件，插上比赛用板，检查能否识别端口；
3. 如果无法识别，打开单片机资源数据包中的USB驱动安装，完成后再次插入板子检查是否成功识别；
4. 选择烧录软件中 **Keil 仿真设置** 的添加型号和头文件，鼠标悬停以查看安装步骤，通常安装在 `C:\keil\C51`；
5. 以**题目要求**（通常是准考证号，但也有可能是别的，按要求操作即可）新建项目，选择匹配的型号。
6. 考场电脑**最后一个盘**没有写保护，**注意备份**。

## 答题时

### 一. 审题，默写框架

调整**跳帽**，根据题意选择**晶振频率**和**键盘**，**定时器初始化的频率要匹配**

常见问题：

​	1）定时器中断`ET0`和总中断`EA`未打开，会导致数码管不显示；

​	2）P2、P0敲错，可能导致数码管乱码、卡死等；

​	3）矩阵键盘未将 P42 和 P44 的值赋给 P36 和 P37 ，会导致矩阵键盘出错；

​	4）负责计数的 xxx_count 达到对应数值后未置 0 ，会导致定时出错，数码管不显示，按键无反应等；

​	5）负责计数的值的取值范围溢出，除非内存不够，否则可以尽量用 `int` 类型，减少变量溢出问题出现的概率。

​	6）使用的标志位在执行过程中记得清零。

​	7）关于按键长按与短按的功能不要产生冲突。

​	8）测频率的P34引脚和NET_SIG引脚，**不用时一定不要用跳帽短接**，会影响键盘或者其他功能。超声波的收发键帽要归位。

​	9）**大胆开关EA，数据闪0就开关EA保证时序****

确保读取外设数据正确，否则后期添加模块出错时无法判断时逻辑出错还是驱动出错。

void Set_Rtc(unsigned char *ucRtc)
{
	unsigned char i;
	Write_Ds1302_Byte(0x8e,0x00);
	for(i=0;i<3;i++)
        Write_Ds1302_Byte(0x84-2*i,ucRtc[i]/10%10<<4|ucRtc[i]%10);//10转16
	Write_Ds1302_Byte(0x8e,0x80);
}

void Read_Rtc(unsigned char *ucRtc)
{
	unsigned char i;
	unsigned temp;
	for(i=0;i<3;i++)
	{
		temp=Read_Ds1302_Byte(0x85-2*i);//读16
		ucRtc[i]=temp/16*10+temp%16;//16转10
	}
}

unsigned char AD_Read(unsigned char channel)
{
	unsigned char temp;
	I2CStart();// 发送开启信号
	I2CSendByte(0x90);// 选择PCF8591芯片，确定写的模式
	I2CWaitAck();// 等待PCF8591反馈
	
	I2CSendByte(channel);// 确定要转换的通道（顺便，使能DA转换）
	I2CWaitAck(); // 等待PCF8591反馈
	
	I2CStart();// 发送开启信号
	I2CSendByte(0x91); // 选择PCF8591芯片，确定读的模式
	I2CWaitAck();// 等待PCF8591反馈
	
	temp=I2CReceiveByte();// 接收数据
	I2CSendAck(1);// 选择不应答
	I2CStop();  // 停止发送
	
	return temp;
}

void DA_Write(unsigned char dat)
{
	I2CStart();// 发送开启信号
	I2CSendByte(0x90);// 选择PCF8591芯片，确定写的模式
	I2CWaitAck();// 等待PCF8591反馈
	
	I2CSendByte(0x40);// 使能DA转换（随便写通道编号，不影响，主要的功能是使能DA）
	I2CWaitAck();// 等待PCF8591反馈// 将待转换的数据发送出去
	
	I2CSendByte(dat);// 将待转换的数据发送出去
	I2CWaitAck(); // 等待PCF8591反馈
	I2CStop();// 停止发送
}

void EEPROM_Write(unsigned char *str,unsigned char addr,unsigned char num)
{
	I2CStart();// 发送开启信号
	I2CSendByte(0xA0);// 选择EEPROM芯片，确定写的模式
	I2CWaitAck();// 等待EEPROM反馈
	
	I2CSendByte(addr);// 写入要存储的数据地址
	I2CWaitAck();// 等待EEPROM反馈
    
	while(num--)

		I2CSendByte(*str++);// 将要写入的信息写入
		I2CWaitAck(); // 等待EEPROM反馈

	I2CStop(); // 停止发送
	I2C_Delay(255);
	I2C_Delay(255);
	I2C_Delay(255);
	I2C_Delay(255);
}

## 串口数据解析

关于strcmp的作用（十国赛）c

- ps:`"ST\r\n"` 是什么？

  - `"ST"`：两个普通字符 `S`、`T`

  - `\r`：回车（Carriage Return，ASCII 13）

  - `\n`：换行（Line Feed，ASCII 10）

所以 `"ST\r\n"` 一共是：`S` `T` `\r` `\n` `\0`（最后自动有字符串结束符 `\0`）。

关于sscanf的作用（十五国赛）

**从一个字符串里按指定格式“解析/读取”数据**（把字符串拆成数字、单词等，存到变量里）。可以理解为“对字符串做 `scanf`”。

- 函数原型

```c
#include <stdio.h>

int sscanf(const char *str, const char *format, ...);
```

- 解释

  - `str`：待解析的源字符串

  - `format`：格式串（和 `scanf` 很像）

  - 返回值：**成功匹配并赋值的项数**（不是字符数）；失败可能返回 0，读不到任何东西可能返回 `EOF`（常见是 -1）

- 用法：

- **示例1**：匹配  **‘(’**  和  **‘，’**  和  **‘）’**并使用unsigned int类型**解析逗号两边的值**并**赋值给**data1和data2

```c
unsigned int data1, data2;
sscanf(Uart_Rec, “(%u,%u)”, &data1, &data2); //如果解析成功就返回2，因为赋值了data1和data2

sccanf(Uart_Rec, “(%u,%u)%n”, &data1, &data2,&Sscanf_Lenth);
//%u,%u是读取的2个数值 如果读取成功sccanf（…………）为2
//%n 是读取的总字符长度 (99,99)  此时Sscanf_Lenth为5
```

- **示例2**：上面的写法会产生一个问题——需要**完全匹配括号**格式时无法识别错误格式
  - **比如**发送数据为“**(0,0#)**”时该函数会找到**(0,0)**并解析成功，同样也返回2，但正确返回应该是“ERROR!”，
  - **解决方法**：再使用通配符 ”**%n**“ 接收 **解析到%n处时已经解析的字符串的个数** （值为int类型），其值必须与**接收到的字符串长度**相等

```c
//串口解析函数
void Uart_Proc(){
	if(Uart_Rec_Index == 1){
		if(Uart_Rec[0] == '?')
        {
			printf("?"); //这里写逻辑
		}
		else if(Uart_Rec[0] == '#')
        {
			printf("#"); //这里写逻辑
		}
		else{
			printf("ERROR");
		}
	}
	else
    {
        //index = 数据长度（不含 '\0'） = Uart_Rec_Index,可以在别处进行赋值判断
		if(sscanf(Uart_Rec, "(%d,%d)%n", &data1, &data2, &Sscanf_Lenth) == 2 && Sscanf_Lenth == Uart_Rec_Index)
        {
			printf("%d,%d,%d", data1, data2, Sscanf_Lenth); //这里写逻辑
		}
		else
        {
			printf("ERROR %d", Sscanf_Lenth); //这里写逻辑
		}
	}
    memset(Uart_Rec,0,Uart_Rec_Index);
    Uart_Rec_Index = 0;
}
```

- 对于`if(sscanf(Uart_Rec, "(%u,%u)%n", &data1, &data2, &Sscanf_Lenth) == 2 && Sscanf_Lenth== Uart_Rec_Index)`这个if语句，我们拆开看
  - `sscanf(...) == 2`这个是用来判断是不是将括号里面的两个数字赋值成功
  - `Sscanf_Lenth== Uart_Rec_Index`来判断是不是**完全等于**`(9,9)`这种格式，防止出现`(9,9#)`这样的格式。
